# Maju Bareng AI for Developers - Final Project

A simple and intuitive chatbot powered by Gemini AI, designed to act as an IT Consultant for users who need expert guidance on technology.

This project is the culmination of the **Maju Bareng AI for Developers** program by **Hacktiv8**.

---

## 🚀 Features

* **AI IT Consultant:** Get instant, smart, and contextual answers to IT-related problems.
* **Intuitive Interface:** Minimalist and easy-to-use chat interface built for seamless user experience.
* **Powered by Gemini AI:** Integrates Google's advanced Gemini API to deliver precise and reliable solutions.
* **Real-time Interaction:** Fast response times tailored to handle complex technical consultation.

---

## 🛠️ Tech Stack

* **Backend:** Node.js / Express.js
* **AI Integration:** Google Gemini API
* **Frontend:** HTML5 
* **Version Control:** Git

---

## 📋 Prerequisites

Before running this project locally, ensure you have the following installed:

* [Node.js](https://nodejs.org/) (v18 or higher recommended)
* npm or yarn
* A Google AI Studio Account to get your **GEMINI_API_KEY**
